# 角色参考图提示词规范

本文档用于约束 `characters/` 下角色参考图的生成流程和提示词写法。目标是保证同一角色在不同形态中的脸部身份一致，并避免“头像提示词生成成全身图”的问题。

## 生成顺序

### 单形态角色

1. 先生成该角色/形态的面部头像图。
2. 再把该面部头像图作为参考图，生成该形态的 `9:16` 正面全身图。

不要直接只用文本提示词生成全身图。

### 同一角色多形态

1. 先确定该角色最先生成的面部头像，作为该角色的身份锚点。
2. 生成其他形态头像时，必须引用身份锚点头像，生成“该形态的面部头像”。
3. 生成该形态全身图时，必须引用“该形态的面部头像”，不要直接引用最初头像。

示例：

```text
柳如烟_封王修士_面部头像.png
  -> 柳如烟_雨夜觉醒_面部头像.png
  -> 柳如烟_雨夜觉醒_9x16全身.png
```

## 头像提示词要求

头像提示词只描述面部、头发、眼神、表情、头饰、肩颈和领口局部。不要把角色 JSON 中的全身提示词整段拼进去。

必须包含：

```text
角色名（形态名），正面面部头像，头肩构图，画面只到胸口以上，脸部占画面主体
```

建议包含：

```text
发型，脸型，眉眼，眼神，表情，肤色，唇色，头饰，领口局部，角色气质，纯色背景，电影写实风格，真实光影，超高清面部细节
```

必须避免：

```text
全身，完整服装，鞋履，脚部，完整裙摆，站姿全景，手持道具，多人，远景，半身到腰
```

头像负向约束建议写入提示词末尾：

```text
不要全身，不要半身到腰，不要脚部，不要完整服装，不要完整裙摆，不要站姿全景，不要多人，不要道具，不要文字。
```

## 全身图提示词要求

全身图必须基于对应形态头像派生，不能独立另写一套脸部设定。

必须包含：

```text
参考输入头像保持角色名（形态名）的面部身份一致，9:16 竖版正面全身角色设定图，人物从头到脚完整入镜，面向镜头
```

可以包含：

```text
完整服装，鞋履，配饰，武器或关键道具，站姿，气质，纯色背景，电影写实风格，真实光影，超高清细节
```

## 群体角色

群体角色不走“单人头像 -> 单人全身图”的流程，也不要拆出一个代表性个体作为身份锚点。群体角色应直接生成对应形态的群像参考图，重点保持人数关系、队形、统一服装和群体气质。

群像图提示词必须明确：

```text
角色名（形态名），群体角色，正面群像参考图，主要人物完整入镜，队形清晰，人数关系明确，统一服装和气质一致
```

可以根据角色卡要求生成全身群像或半身群像；如果后续用于视频或分镜角色参考，优先使用 9:16 竖版全身群像，保证前排主要人物从头到脚完整入镜，后排人物作为群体关系补充。

文件命名建议：

```text
角色名_形态名_群像.png
角色名_形态名_9x16群像.png
```

不要为群体角色生成 `面部头像.png`，除非用户明确要求拆出某个具体个体。

## 抽象角色

没有实体人身的角色，例如 `天道`、`系统`、`规则界面`，不要强行写普通人物头像。应定义为“头像式核心符号”或“正面核心形象”：

```text
天道（誓言雷云），正面核心符号头像，画面中心是金白规则纹与雷云凝聚成的面部轮廓，头肩式构图，主体占画面中心...
```

全身图阶段再扩展为完整规则实体、光幕、雷云或神识空间形象。

## 安全与风格

- 遇到 `血`、`吐血`、`杀`、`围攻` 等可能触发安全系统的词，优先改写为非血腥表达，例如 `脸色苍白`、`虚弱倒下`、`对峙`、`冷眼反制`。
- 角色提示词使用中文自然语言，不堆叠英文标签。
- 不要把 Markdown、注释或无关说明写入 JSON 输出。

## 文件命名

头像：

```text
角色名_形态名_面部头像.png
```

全身图：

```text
角色名_形态名_9x16全身.png
```

测试样张可以临时加后缀：

```text
角色名_形态名_面部头像_重生成.png
```

确认采用后，应覆盖或重命名为正式文件名。

## 交付校验

完成后至少检查：

```bash
find characters/<项目名>/<角色名>/images -maxdepth 1 -type f -print
file characters/<项目名>/<角色名>/images/*.png
sips -g pixelWidth -g pixelHeight characters/<项目名>/<角色名>/images/*.png
```

头像应为 `1:1`；全身图应接近 `9:16`。如果文件名是 `面部头像`，但实际画面是全身图，必须重生成头像后再生成全身图。
