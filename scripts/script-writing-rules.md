# 分镜剧本写作规则

本文件约束 `scripts/` 下所有分镜剧本产物，尤其是 `script.json` 和 `script.md`。如用户另有明确要求，以用户当前要求为准，但需要在产物中保持说明。

## 1. 单镜头时长

- 默认每个分镜视频时长固定为 `15s`。
- `script.json` 中每个 shot 的 `duration` 必须写为 `"15s"`。
- 整集目标时长应按镜头数计算，例如 16 个镜头时 `duration_target` 应为 `"240s"`。
- 如确需改成其他时长，必须先说明原因并得到用户确认。

## 2. 详细节拍字段

每个 shot 除基础字段外，应包含：

- `detailed_beats`：固定 3 段，按 `0-5s`、`5-10s`、`10-15s` 描述镜头推进。
- `visual_focus`：概括本镜头必须看清的画面重点。
- `performance_notes`：说明角色表演、情绪层次、镜头避免误读的要点。

`detailed_beats` 不能只复述剧情摘要，必须写出动作、表情、站位、镜头变化、证据呈现或情绪转折。

## 3. 改编原文细节

小说改编项目生成剧本时，必须对照原文细节：

- 原文中同场角色必须进入对应镜头的 `characters`，不要遗漏关键在场人物。
- 原文关键动作必须落到镜头里，例如“同床醒来”“无意识收紧手臂”“伸手未碰到衣角”。
- 原文关键对白应尽量保留或改写为同义短句，不要只用旁白概括。
- 原文证据链、反转点、站位关系必须清楚呈现，不能只写“真相公开”“众人震惊”。

## 4. 场景与状态准确性

- 镜头 `scene` 必须写真实发生地，不要把意象、惩罚去处、回忆结果误写成当前场景。
- 可以在 `detailed_beats` 中短暂闪过意象画面，但 `scene` 仍应保持主事件发生地。
- 角色变体必须符合镜头时间点。例如回放中的楚执柔仍是“白裙柔弱”，不能提前使用“吐血昏倒”。
- 角色在前一镜头的状态若延续到后一镜头，要保持一致。例如时子初在星澜怀中哭诉时，应使用“梨花带雨”，不要突然切成“冷眼反杀”，除非镜头明确表现表情切换。

## 5. 角色引用完整性

- 每个镜头必须列出对画面理解必要的在场角色。
- 如果角色虽未说话但影响动作或构图，也必须加入 `characters`。
- 示例：开场时子初和星澜同在床榻上，即使第一镜重点是系统警报，也必须包含 `星澜（寝殿里衣）`。
- 对白 `speaker` 必须出现在同镜头 `characters` 中。

## 6. 质量自检

剧本完成或修订后，至少检查：

- JSON 可被标准解析器解析。
- 所有镜头 `duration` 都是 `15s`。
- 每个镜头都有 3 段 `detailed_beats`。
- 角色名、角色变体、场景名、场景变体、道具名都能追溯到 Phase 2 设计文件。
- 第一幕、反转镜头、结尾钩子不遗漏原文关键角色和关键动作。
- `script.md` 与 `script.json` 的镜头号、时长、角色、场景、对白保持一致。
