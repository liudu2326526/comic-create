# 第1集规划：重生刑堂翻盘

## 基础信息

- 集数：第1集
- 标题：重生刑堂翻盘
- 来源章节：第1章稿件
- 预计时长：1-2分钟
- 预计镜头数：12-16

## 核心事件

时子初在系统警报中重生，发现自己回到与师尊星澜牵扯不清后的清晨；刑堂传唤她接受“推楚执柔入百妖谷”的审问，她带着前世惨死记忆冷静赴审，以证据反问、天道誓言和复原留影石打破栽赃，最终借星澜入场护短，让徐舟野等偏信同门被罚去思过崖。

## 涉及角色

- 时子初
- 星澜
- 楚执柔
- 徐舟野
- 几位师弟
- 刑堂堂主
- 玉虚宗宗主
- 女配系统
- 天道

## 主要场景

- 星澜寝殿
- 星澜主峰门外
- 玉虚峰刑堂
- 青山秘境记忆画面
- 百妖谷边缘
- 思过崖

## 情绪走向

系统警报 -> 重生错愕 -> 寝殿尴尬 -> 前世怨恨 -> 刑堂围攻 -> 冷静反问 -> 天道誓言 -> 星澜护短 -> 留影石反转 -> 思过崖惩罚

## 集尾钩子

徐舟野和几位师弟听见“思过崖面壁”后震惊抬头，楚执柔倒在地上昏迷不醒。时子初埋在星澜怀里，眼泪未干，唇角却在无人看见的角度轻轻勾起。

## 关键节拍

1. 系统警报在时子初脑海中尖锐响起，提示系统正在遭受不明攻击。
2. 时子初睁眼，发现自己回到星澜寝殿，意识到重生节点极其危险。
3. 她确认环初铃在神识海中，忍着身体不适准备趁星澜未醒逃离。
4. 刑堂长老在主峰外传唤，要求星澜交出时子初接受青山秘境审问。
5. 时子初想起前世被女配系统操控、被同门误判、被逐出宗门后的惨局。
6. 星澜醒来，语气冷淡却没有责罚她，反而以灵力替她缓解不适。
7. 时子初试探星澜态度，发现他似乎知道她想要的东西已经到手。
8. 她没有把全部筹码押在星澜身上，而是独自前往玉虚峰刑堂。
9. 刑堂内，楚执柔装作柔弱求情，徐舟野和师弟们不分青红皂白指责时子初。
10. 时子初没有按前世那样失控怒骂，而是冷静追问“证据呢”。
11. 留影石被称已经损坏，时子初当场向天道立誓自证没有推楚执柔。
12. 天道认可誓言，天雷没有落下，楚执柔和众人开始动摇。
13. 星澜带着威压进入刑堂，见时子初孤立无援后怒意爆发。
14. 玉虚宗宗主带来复原留影石，水镜播放青山秘境真相。
15. 画面证明时子初并未碰到楚执柔，楚执柔伪善崩盘并吐血昏倒。
16. 时子初借哭诉继续追击，星澜罚徐舟野等人去思过崖面壁。

## 下游设计提示

- 角色设计需给时子初拆出“寝殿惊醒”“刑堂白裙”“梨花带雨”“冷眼反杀”四个状态。
- 星澜设计要突出清冷尊者、白衣、威压和护短气质。
- 场景设计重点是星澜寝殿的清冷私密感与玉虚峰刑堂的压迫审问感。
- 道具设计重点是环初铃、留影石、水镜、天道誓言和思过崖。
