# 故事大纲：清冷师尊爬我墙

## 1. 基础信息

- 作品名称：清冷师尊爬我墙
- 来源：改编自《清冷师尊爬我墙》第1章稿件
- 写作视角：第三人称贴近时子初视角，穿插前世记忆和反派心理
- 视觉风格：古风仙侠电影写实
- 剧本风格：重生复仇甜宠爽文漫剧
- 目标集数：1集起步，后续可按新增章节继续扩展
- 每集时长：1-2分钟

## 2. 时空背景

故事发生在修真宗门玉虚宗。宗门表面讲究师门秩序、刑堂公正和天道誓言，内部却已被女配系统、偏心同门和真假证据搅乱。主角时子初前世被系统强制绑定并操控身体，被迫卷入楚执柔的栽赃，最终众叛亲离、灵根被挖、容貌被毁。重生后，她回到命运崩坏的起点：与清冷师尊星澜牵扯不清后的清晨，以及青山秘境“推人入百妖谷”的刑堂审问。她必须在最短时间内脱离系统操控、抢回话语权，并利用天道誓言和师尊态度反转局面。

## 3. 叙事结构

- 结构类型：重生开局 + 刑堂打脸 + 师尊护短
- 递进模式：系统警报开场，时子初确认重生节点；寝殿逃离被刑堂传唤打断；她回忆前世惨局后决定主动破局；刑堂众人先入为主定罪；她以证据、天道誓言和复原留影石完成反杀；星澜公开护短，师兄弟被罚入思过崖。
- 情绪曲线概要：惊醒错愕 -> 禁忌尴尬 -> 前世怨恨 -> 冷静赴审 -> 被众人围攻 -> 天道立誓反转 -> 星澜入场撑腰 -> 留影石真相公开 -> 楚执柔崩盘 -> 师兄弟受罚

## 4. 核心冲突

时子初前世被女配系统操控，被迫成为楚执柔的垫脚石，并在同门偏信中失去一切。重生后，她既要摆脱系统遗留影响，又要在所有人都预设她有罪的刑堂现场自证清白。她的破局方式不是单纯哭闹，而是借天道誓言、留影石真相和星澜的护短，把楚执柔的伪善、师兄弟的偏见和刑堂的失职一并反打。第一章的核心爽点，是她从“被剧情按头的恶毒女配”转为“清醒控局的重生者”。

## 改编重点

- 第1集核心不是铺世界观，而是快速建立“重生 + 系统受损 + 师尊关系 + 刑堂诬陷 + 当场反杀”。
- 时子初的镜头要兼具娇软外壳和冷静内核，哭诉不是被动示弱，而是主动借势。
- 星澜的镜头要突出清冷、威压和护短，不要只写成普通恋爱对象。
- 楚执柔和徐舟野阵营要承担第一轮打脸对象，观众需要清楚看到“他们没有证据却先入为主”。
- 后续扩展应继续追踪三条线：女配系统为什么受攻击、星澜是否知道更多真相、时子初如何清算前世旧仇。
